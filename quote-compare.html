02 / 견적서에 적힌 내용

최대 세 업체를 같은 조건으로.

견적서 사진에서 글자 읽기(OCR)를 하거나 항목을 직접 입력하세요. 업체별 최대 10장·200개 항목. OCR은 사진의 의미를 분석하지 않으며, 금액·규격은 원본 대조가 필요합니다. PDF는 비교할 쪽을 JPG·PNG로 저장해 넣어주세요.

‘별도’ 견적에만 더합니다. 세액·면세 여부는 업체에 확인하세요.

03 / 현장에서 보이는 것

사진에, 확인할 일을 붙이세요.

최대 12장 · 설명은 직접 수정

전체 모습과 가까이 찍은 모습을 함께 준비하세요. 관찰한 사실과 궁금한 점을 나누면 업체와 이야기하기 쉬워집니다.

사진은 이 기기에서 보고서용 크기(긴 변 최대 1,600px)로 줄입니다. 원본 정밀 사진은 따로 보관하세요. 여기서는 사진을 AI에 자동 전송하지 않습니다.

05 / 누락 단정 대신, 확인 질문

사진만으로 내부 상태나 필수 공사를 확정할 수는 없습니다. ‘견적에 적혔는지’와 ‘실제로 필요한 작업인지’를 나눠 확인하세요.

기본 질문은 사진 분석 결과가 아닌 일반적인 점검 목록입니다. 해당하지 않는 질문은 지우세요.

PDF는 인쇄 창에서 ‘PDF로 저장’을 선택하세요. HTML 보고서는 사진을 포함한 독립 파일로 저장됩니다. 글꼴·쪽 나눔은 브라우저에서 확인해 주세요.

자료 처리·비교 기준

사진과 입력은 이 브라우저 메모리에서만 다루며 AI봄 서버로 전송하지 않습니다. 새로고침·페이지 이동 시 사라집니다. 보고서 파일 저장은 이용자가 직접 선택합니다. 현장 사진은 캔버스에서 JPEG로 다시 만들어 보고서에 넣으며, 원본 파일은 바꾸지 않습니다.

견적서 사진의 ‘글자 읽기’는 Tesseract.js와 한글·영문 인식 자료를 외부 CDN에서 내려받아 기기 안에서 실행합니다. 첫 실행에는 인터넷과 시간이 필요하며 인식 자료가 캐시될 수 있습니다. PDF 직접 분석은 지원하지 않습니다.

견적 항목은 입력한 이름이 같은 행끼리 연결합니다. 같은 이름의 여러 행은 합산합니다. 동일한 제품·시공 범위인지는 사람이 확인해야 합니다. ‘대응 행 없음’은 누락 공사 확정이 아닙니다. 금액은 산술 비교이며 업체 추천·적정 시세·시공 안전성 판정이 아닙니다.

외부 AI에 원본을 직접 올리면 해당 서비스의 자료 처리 정책이 적용됩니다. AI 답변은 사실 확인 전 초안으로 표시합니다. 이 도구의 보고서는 검토·상담을 위한 정리 자료이며 감리·안전진단·전문 견적서를 대신하지 않습니다.
