이 브라우저에서는 애니메이션을 표시할 수 없습니다.

완성된 영상, 먼저 보고 골라요

아래 재생 버튼으로 실제 저장될 영상을 끝까지 확인하세요. 보기 좋은지 확인한 뒤 저장해 주세요.

WebM 형식의 무음 영상입니다. 저장 전에 기기에서 재생되는지 확인해 주세요.

② 저장한 카드를 카톡에 첨부하세요

컴퓨터: 카톡 채팅창 아래 파일 첨부(종이 모양) → 다운로드 폴더 → 봄담이_마음카드.png 선택 → 전송

휴대폰: 카톡 채팅방 ＋ → 파일 → 다운로드에서 선택하세요. 사진 목록에 보이면 사진으로 첨부해도 돼요.

파일 복사·붙여넣기나 앱 공유 대신, 저장한 파일을 직접 첨부해 주세요. 사진 카드는 움직이지 않아요. 영상은 먼저 완성본을 재생해 보고 마음에 들 때 저장하세요. 영상 파일은 무음 WebM입니다.

문구를 바꾸고 카드를 미리 보세요.

영상은 현재 브라우저에서 직접 만들어 저장해요. 목소리는 기기의 음성 합성 기능으로 재생돼요. 저장한 WebM 파일에는 소리가 포함되지 않습니다. MP4나 음성 추가는 별도 편집이 필요해요.

이름과 문구를 저장하는 서버는 없습니다. 카드 저장 후, 내가 선택한 채팅방에 직접 첨부하세요.
